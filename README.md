## Add the repo

Open [jond-ie.github.io/repo](https://jond-ie.github.io/repo/) on your iPhone and tap **Add to Sileo** or **Add to Zebra**. Or add this source by hand:

```
https://jond-ie.github.io/repo/
```

## Start with these

- **[Triggr](https://jond-ie.github.io/repo/triggr/)**: make any button, gesture or event do anything. Activator, rebuilt for iOS 15–27.
- **[Crest](https://jond-ie.github.io/repo/crest/)**: a music player for your own songs that plays them exactly as good as the files are.
- **[Catapult](https://jond-ie.github.io/repo/catapult/)**: make your iPhone's Home Screen work like Android's.

There are plenty more: Lock Screen, Face ID, look and feel, privacy, music, tools and fixes. **[Browse them on the site](https://jond-ie.github.io/repo/)**: each one is tagged with the iOS versions it works on.

## Will it work on my phone?

You need a Rootless jailbreak (Dopamine, palera1n) or RootHide. Catapult also has a rootful build. It's one repo for both: your package manager only shows the build made for your jailbreak. Each tweak's page says which iOS versions and jailbreaks it supports, and which ones it's tested on. Everything is tested on real iPhones, from the iPhone 7 to the iPhone 11 Pro.

## Bugs and requests

[Open an issue](https://github.com/Jond-ie/repo/issues) with your iPhone model, iOS version and the tweak's version. If a tweak ever puts you in safe mode, uninstall it in your package manager first.
