FaceSkip

Face ID goes straight to the Home Screen. No swipe up after your face is recognised.

  • Stays on the Lock Screen when it should (each one optional, in Settings → FaceSkip): when notifications are showing (on by default, so you can read the previews), when music is playing (on) or when the flashlight is on (off).
  • Never leaves StandBy, and never pulls you away from the widgets or camera page.
  • Light: one small hook that only runs when Face ID recognises you. Nothing runs in the background.
  • Safe: iOS itself still decides whether the Lock Screen can be dismissed, so it can't unlock into anything unexpected.

Device Support

  • iOS 18 and later, Face ID iPhones. arm64 and arm64e builds.
  • Tested on an iPhone 11 Pro (A13) with iOS 18.6.2 and Dopamine rootless. Newer iOS versions aren't confirmed yet: please report back.
  • If it ever puts you into safe mode, open Sileo (safe mode still allows it) and uninstall it.
