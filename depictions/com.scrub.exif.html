Scrub

Removes GPS and identifying metadata from photos before apps receive them for sending — so your location and device details don't ride along with a shared image. Orientation and color profile are preserved; JPEG and HEIC supported.

Modes and a per-app exclude list in Settings → Scrub.

Device Support

A12 and newer: supported and confirmed. Earlier builds put A12+ devices (iPhone XS / XR and later) into safe mode; the current builds are made with Xcode's toolchain and are tested on a real A12+ device.

  • Tested on an iPhone SE (2nd gen, A13) with iOS 17.5.1 (arm64e) and an iPhone 8 Plus (A11) with iOS 16.7, both with Dopamine. On iOS 17 it installs and loads cleanly; stripping wasn't re-checked there (no GPS photos on the test phone).
  • If it ever puts you into safe mode: open Sileo (safe mode still allows it), uninstall it and please report back.

Notes

  • Covers the common photo-pick paths (Photos library, the system picker). Coverage can vary for apps using custom pickers — feedback on which apps work welcome.
  • Requires AltList (com.opa334.altlist) for the app list, plus PreferenceLoader; hooks run via ellekit/Substrate.
  • Tested on an iPhone 8 Plus (A11, arm64) with iOS 16.7. A12 and newer: see Device Support.
