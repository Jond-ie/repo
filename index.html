A12 and newer: supported again, not confirmed yet. Earlier builds put A12+ devices into safe mode; the current versions use a new build toolchain. Please report back. If one puts you into safe mode, uninstall it in Sileo.

Tweaks

Begonecia port

Control Center toggle that silences camera, microphone and location system-wide — total blackout, no permission errors. Rootless port of Nepeta's BegoneCIA (MIT).

Original BegoneCIA (mirror) · Source code

Slaplock

Gate any app behind the stock Face ID / Touch ID prompt. Per-app, all off by default.

Triggr beta

Activator-lite: assign actions to the home, lock and volume buttons, Touch ID, status bar taps, Home Screen icon flicks, shaking and events. Open source (GPL-3.0). The build here is arm64 (A11 and older); A12+ devices can try the experimental arm64e build on GitHub (untested on A12+ yet).

Details · Source & feedback on GitHub

Pinstant

Wake straight to the passcode: no Lock Screen, no swipe, no wait. No settings. Concept from UnlockOrElse by Ethan Whited (ETHN).

Details

BlankPass

A blank Lock Screen passcode keypad: the numbers are hidden, the circles stay. No settings.

Details

Density beta

More on screen in the apps you pick, like Android's display density. The status bar and keyboard stay stock; one slider, then switch it on per app.

Details

Podified

Makes a SIM-less iPhone present itself as an iPod: iPod naming in Settings, no Cellular, an "iPod" status bar and an optional hidden Phone app. Cosmetic only.

Crossfade

True crossfade between local-library tracks in the stock Music app. For your own files — no subscription needed.

Scrub

Removes GPS & identifying metadata from photos before apps send them. Preserves orientation and color.

Heads-up: jailbreaking itself lowers your device's baseline security. These tweaks harden your privacy (what apps see and send); they don't undo that tradeoff. Install what you need, nothing more.
