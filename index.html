Install

  1. Add the repo. Tap Add to Sileo or Add to Zebra. Rootless and RootHide use the same address.
  2. Find the tweak. Search its name, or open Jond_ie in your sources.
  3. Install it. Settings, if it has any, are in the Settings app.
